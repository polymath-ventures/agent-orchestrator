# Skeleton

Loading placeholder. Size it with utility classes to match the content it
stands in for.

```tsx
<div className="flex flex-col gap-2">
	<Skeleton className="h-4 w-40" />
	<Skeleton className="h-4 w-64" />
</div>
```

Mirror the real layout's shape — a skeleton that doesn't match causes a jump.
